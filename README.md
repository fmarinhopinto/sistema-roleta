# 🎯 Sistema Roleta - Controle Comercial

Aplicação web desenvolvida em Streamlit para consolidação e automação das planilhas de controle comercial da Roleta.

### 📋 Funcionalidades
- **Aba 1 (Reativados - Novos):** Cruzamento automático das bases de Clientes Novos, Clientes Reativados e Pedidos do Acompanhamento, com identificação de vendedor e valores.
- **Aba 2 (Propostas Enviadas / Efetivadas):** Tabela dinâmica automática com contagem de status por vendedor a partir do relatório ADM.
- **Download:** Geração em tempo real do arquivo `.xlsx` oficial formatado para premiação e acompanhamento.
